# Scoring Engine logic
Score 0-20 for each category (Total 100):
1. **Strategic Clarity:** Clear offer + clear goal?
2. **Asset Readiness:** Do we have everything to build?
3. **Revenue Potential:** Is this a High-Value Tier client?
4. **Risk Profile:** Absence of red flags.
5. **Agency Fit:** Does this match our core competency?

Tiers:
- 80-100: Green Light (Launch)
- 60-79: Yellow Light (Standard Onboarding)
- 40-59: Orange Light (Review required)
- <40: Red Light (Hold/Deny)
